# Peripheral database sources

The files in this directory are generated by `go run ./core/periph/gen -out core/periph/data`
from the vendor register description files listed below. The generator keeps
only register/field/enumeration names and descriptions (descriptions are
whitespace-normalised and truncated to 600 characters), interrupt names and
peripheral address blocks; memory maps of ARM/RISC-V/Xtensa parts are written
by hand in `gen/devices.go` from the datasheets.
